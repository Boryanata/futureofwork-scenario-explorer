# O*NET Raw Data

Put the downloaded O*NET CSV files here.

## Required Files

```text
Occupation Data.csv
Task Statements.csv
Task Ratings.csv
Essential Skills.csv
Transferable Skills.csv
Work Activities.csv
Job Zones.csv
Job Zone Reference.csv
Scales Reference.csv
Task Categories.csv
```

## What Each File Provides

```text
Occupation Data.csv       -> occupation title, O*NET-SOC code, description
Task Statements.csv       -> occupation task statements
Task Ratings.csv          -> task importance, relevance, and frequency ratings
Essential Skills.csv      -> core occupation skill ratings
Transferable Skills.csv   -> cross-job skill ratings
Work Activities.csv       -> generalized work activity ratings
Job Zones.csv             -> job zone number by occupation
Job Zone Reference.csv    -> job zone meanings and training/education descriptions
Scales Reference.csv      -> meanings of rating scales
Task Categories.csv       -> meanings of task frequency categories
```

All these files connect through `O*NET-SOC Code`.
